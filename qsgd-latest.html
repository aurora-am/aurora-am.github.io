1. 原油链（SC / 布伦特 / WTI / FU / PG / BU / TA）数周

原因类型：供给扰动 + 地缘冲突 + 库存去化
霍尔木兹海峡通行量 600–700 万桶/日 → 200–300 万桶/日（Kpler）→ 中东出口减量 >1000 万桶/日 → 陆上库存 8–9 月重回去化 → 现货溢价走阔（北海现货较期货升水 13 美元/桶）→ 盘面脉冲
  • 沙特东西输油管道 9/11 关闭（预防性，遭无人机袭击），交易商称若数日内不恢复，全球供应损失约 4%；该管道是霍尔木兹受阻后沙特红海转运主力（延布港出口 150→450 万桶/日）。
  • 阿曼会议推迟：原定 9/14 在塞拉莱举行的霍尔木兹新通道会议推迟，缓和预期落空，油价应声大涨。

  • 成品油裂解创新高：ICE 柴油裂解 92.73 美元/桶、NYMEX 取暖油 111.90 美元/桶，均创年内新高（中信证券 9/14）。
持续性判断依据（数周）：中金下调中东复产预测——4Q26 中东产量或仍低于冲突前 700–800 万桶/日（占全球 7–8%），复产进程至少延至 1Q27；同时全球陆上库存低于前期，放大溢价弹性。反向约束：中金同时提示油价破百后"需求顶"将显现，新加坡裂解价差已高位回落，属脉冲而非趋势。

2. 集运欧线 EC +2.84%数日

原因类型：地缘冲突 → 绕行 + 燃油成本

持续性判断依据（数日）：EC 是运价指数不是运量，地缘溢价脉冲性极强；今日盘中一度 +6%（报 2167.5），10:47 已回落至 +2.84%，日内振幅巨大，不具备数周级别趋势特征。
