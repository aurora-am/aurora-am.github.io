完整规则体系阈值与权重

① 个股强弱分级（9 级）

挂载 MA5, MA13, MA21, MA34, MA55, MA89, MA144, MA233 共 8 条斐波那契均线。 收盘价站上 N 条 → 强弱级别 = N+1，取值 1~9。

  • 9 级：站上全部 8 条，全周期多头趋势
  • 5 级：站上 4 条，多空平衡
  • 1 级：站上 0 条，全周期空头趋势

② 板块强弱指标

板块强弱分 = 板块内所有个股强弱级别的算术平均（等权），区间 1~9。 分档：≥7.0 极强 / ≥6.0 强势 / 4~6 震荡 / ≤3 弱势。

并列输出两个校正指标：加权分（按申万官方「最新权重」加权， 用于识别小盘板块被个别权重股拉高的失真）；分化度（板块内个股级别的标准差， ≥2.2 时提示内部分化严重，需结合涨/跌家数判断）。

③ 阶段判定（启动 / 强势 / 调整 / 弱势）

四象限：看强弱分水平 × 3 日趋势。

强弱分趋势≥0.15趋势<0.15
≥6.0强势期调整期
<6.0启动期弱势期

④ 真拐头确认（过滤单日脉冲）

向上需同时满足：连续 3 日抬升且累计 ≥0.3； 上涨家数占比 ≥60%；成交额较 20 日均值放大 ≥1.15 倍； 有效站上 5/6/7 关键阈值。

向下需同时满足：连续 2 日回落且累计 ≤-0.3； 下跌家数占比 ≥55%；反弹缩量 / 下跌放量。

阈值附近反复上穿下穿（≥4 次翻转）判为「震荡磨方向」，不算有效拐头。

⑤ 背驰判定

板块指数日线级别 MACD 柱面积对比：价格创新高但 MACD 柱面积较前高收缩至 75% 以下 → 顶背驰； 价格创新低但 MACD 负柱收敛 → 底背驰。回看窗口 60 日。

⑥ 个股筛选硬门槛（全部满足才入选）

  1. 龙头：5 日涨幅板块内前 20% 或 20 日相对强度前 30%
  2. 缠论环境：站上 MA5/13/21/34 中至少 3 条
  3. 量价配合：5 日均量/20 日均量 ≥1.15，当日量比 ≤3.5
  4. 相对强度：20 日涨幅 > 板块指数 20 日涨幅
  5. 拥挤度：换手率 ≤25.0%，流通市值 ≥20.0 亿

综合分 = 龙头分位×40 + 强度分位×25 + 均线数×10 + 量能×10 + 回踩守MA13×8 + 守MA21×5 + 回踩缩量×5 + 涨停基因×7 + MACD柱抬升×3
